COMO ACESSSAR?

Fábio, abre o aquivo `index.html` para acessar a página inicial.

Pelo menu superior você vai poder acessar as seguintes páginasss:

- Home
- NAPNE
- Projetos
- Acessibilidade
- Relatos
- Entrar
- Cadastrar

USUÁRIO

O visitante pode acessar e visualizar as páginas normalmente.
A única diferença do usuário logado é que, depois de realizar o cadastro e login, ele pode **publicar relatos**.
Esses relatos são direcionados para paginas de adm para revisão e confirmação ou exclusão dos mesmos.

Para testar: 

1. Clique em **Cadastrar**.
2. Crie uma conta usando os dados que desejar.
3. Faça login.
4. Acesse **Relatos**.
5. Agora será possível realizar uma publicação.

Caso tente publicar sem estar logado, o sistema solicitará que o usuário faça login ou cadastro.

O projeto utiliza `localStorage` (dona AI me apresentou )para armazenar os dados durante a demonstração.
